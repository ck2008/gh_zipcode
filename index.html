台灣 3+3 郵遞區號 查詢

輸入完整地址可獲得較精確的 3+3 結果。

API 使用說明

可免 API key 直接以 GET 呼叫，支援 CORS 與繁、簡體中文地址。

端點：https://skubqoeizqgbixaaxfeq.supabase.co/functions/v1/zipcode?adrs=地址

範例：查詢「臺北市信義路五段7號」

  • adrs：必填，UTF-8 地址，最長 200 字元。
  • zipcode6：第一筆命中的 3+3 郵遞區號；results：全部命中範圍。
  • 回傳欄位只有 adrs、zipcode6、dataver6、results。
  • 每個來源每分鐘最多 30 次；請勿作大量批次查詢。
